## Menjalankan
Buka `index.html` pada browser modern. Tidak membutuhkan backend, API, atau database server. Data operasional disimpan pada **IndexedDB** browser.

## Hak akses
Hanya admin yang dapat membuat/mengubah/menghapus inventaris, mencatat transaksi, mengubah pengembalian, mengatur denda, dan melihat audit.
